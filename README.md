# Väinölang

Väinölang is a Zig-compatible language fork for the Väinö project.
Upstream Zig is the source of truth; Väinölang takes the best parts
via selective cherry-picks and adds only small, opt-in Väinö extensions.

See [ROADMAP.md](ROADMAP.md) for the 0.17 cherry-pick plan and the
small-extension policy.
